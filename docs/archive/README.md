# Archived: the cell coordinator

These pages describe the multi-cell coordinator — rings, epochs, placement policy, and the client
cache that went with it. The code is still in the repo (`:coordinator`, `:placement`), but the
documentation no longer leads with it: wiggle is documented as a server and a client.

Nothing here is deleted. To put a page back, move it up one level and re-add its entry to
`DOCS_NAV` in the wiggle-site `build.py`.
